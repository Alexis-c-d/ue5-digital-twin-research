# UE5 Digital Twin Research
Evaluación de la fidelidad física de Unreal Engine 5 como entorno de simulación para robots móviles diferenciales.

## Research Overview
This repository documents a research project evaluating the physical fidelity of Unreal Engine 5 as a simulation environment for differential-drive mobile robots.

## Published Paper
**Videojuegos Realistas? Unreal Engine como base de simulaciones para robot móviles**
- Author: Luis Alexis Calvillo Deveze
- Advisor: Prof. Javier Camacho Barajas
- Course: Escritura Académica

## Research Topic
**Evaluación de la fidelidad física de Unreal Engine 5 como entorno de simulación para robots móviles diferenciales**

## Research Question
¿Qué tan precisa es la simulación física de Unreal Engine 5 al representar el comportamiento cinemático de un robot móvil diferencial en comparación con los modelos matemáticos teóricos?

## Hypothesis
Unreal Engine 5 puede reproducir el comportamiento cinemático de un robot móvil diferencial con un error inferior al 5 % respecto a los resultados obtenidos mediante modelos teóricos en condiciones controladas.

## Key Findings
- **Position errors**: 25.47% (slow straight), 21.82% (medium straight), 18.31% (fast straight), 51.02% (curved trajectory)
- **Angular errors**: 90.88% (slow turn), 67.47% (fast turn)
- **Conclusion**: Under the tested configuration, Chaos Physics did not reproduce the ideal kinematic behavior with sufficient precision (errors exceeded the 5% acceptance criterion). Unreal Engine 5 is useful for visualization and prototyping but requires physics calibration before use as a reliable robotic validation tool.

## Methodology
1. **Virtual Robot Design**: Differential-drive robot with rigid chassis and two drive wheels on flat surface
2. **Physical Simulation**: Movement generated by wheel-ground interaction via Chaos Physics, not predefined coordinates
3. **Test Cases**: 
   - Rectilinear displacement (3 speeds: slow, medium, fast)
   - Rotation on own axis (slow, fast)
   - Curved trajectory
4. **Comparison**: Simulation results vs. theoretical kinematic model
5. **Acceptance Criterion**: ≤5% error

## Key Parameters
- Wheel radius: 0.05 m
- Wheel distance (track width): 0.30 m
- Test duration: 5 seconds
- Acceptance criterion: 5% error

## Theoretical Model
Differential-drive kinematic equations:
- Linear velocity: v = (r/2)(ω_R + ω_L)
- Angular velocity: ω = (r/L)(ω_R - ω_L)
- Straight: x = vt, y = 0
- Rotation: θ = ωt
- Curved: x = (v/ω)sin(ωt), y = (v/ω)(1-cos(ωt))
